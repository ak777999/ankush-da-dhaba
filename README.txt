ANKUSH DA DHABA — Apni Thali Khud Banao (demo)
------------------------------------------------
Kholne ke liye: index.html par double-click karo (Chrome/Edge). Internet ki zaroorat nahi.

Kaise chalta hai:
 1. Left dial se ek item chuno -> wo udd ke thali ki katori mein girega, receipt mein jud jayega.
 2. Dial apne aap agli category par ghoomega (Roti/Chawal -> Dal -> Sabzi -> Crunchy -> Meetha).
 3. Thali mein kisi bhari katori par click = hatao/badlo. Upar 1-5 gol buttons se kisi bhi step par jao.
 4. 5/5 hone par receipt mein "PACK KARO!" -> dhakkan girega -> "KIDHAR BHEJNA HAI?" form.
 5. "ORDER KARO!" = sirf demo success message (koi payment/delivery nahi). "Nayi Thali" = reset.

Files: index.html, assets/style.css, assets/app.js, assets/food/*.webp (AI-generated food photos),
assets/fonts/* (Shrikhand, Bungee, Archivo Black, Courier Prime, Baloo 2, Baloo Paaji 2 — sab OFL free fonts).
