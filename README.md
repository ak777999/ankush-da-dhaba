# Ankush Da Dhaba

Interactive Indian thali ordering demo website.

## Official GitHub Pages URL

https://ak777999.github.io/ankush-da-dhaba/

This URL goes live after Pages is enabled:

1. Open [Settings → Pages](https://github.com/ak777999/ankush-da-dhaba/settings/pages)
2. Under **Build and deployment**, set **Source** to **GitHub Actions**
3. Open the **Actions** tab, run the **Deploy to GitHub Pages** workflow, and wait 1–2 minutes
